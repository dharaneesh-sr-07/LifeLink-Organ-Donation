# ❤️ LifeLink – Organ Donation Website

### Connecting Lives, Creating Hope

LifeLink is a web-based Organ Donation Registration System developed to make donor registration simple and accessible. It allows users to submit their donor details through an easy-to-use website and stores the information securely in an SQLite database using Java JDBC.

🌐 **Live Website:** https://lifelink-organ-donation-thez.onrender.com

💻 **GitHub Repository:** https://github.com/dharaneesh-sr-07/LifeLink-Organ-Donation

---

## 📌 Project Overview

Organ donation plays an important role in saving lives. LifeLink aims to provide a simple digital platform where interested individuals can register their willingness to donate organs.

The system collects donor information through a web form, processes the submitted details using Java, and stores the records in an SQLite database.

## 🎯 Objectives

- Provide a simple online donor registration form.
- Collect basic donor information.
- Store donor details using JDBC connectivity.
- Display registered donor records.
- Develop an easy-to-use and responsive web interface.
- Demonstrate Java database connectivity in a real-world application.

## ✨ Features

- 📝 **Donor Registration:** Users can submit their details through an online form.
- 🩸 **Blood Group Selection:** Users can select their blood group.
- 🫀 **Organ Selection:** Users can select the organ they are interested in donating.
- 🗄️ **Database Storage:** Donor details are stored in an SQLite database.
- 📋 **Donor Records:** Displays registered donor information.
- 🌐 **Web Interface:** Simple interface developed using HTML and CSS.
- ☕ **Java Backend:** Handles form submissions and database operations.
